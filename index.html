🔥 Real-time Database Setup

Connect your free Firebase project so you and your friends can register with Google, match each other, and chat in real-time!

  1. Go to console.firebase.google.com & create a free project.
  2. In the sidebar: Authentication → Enable Google sign-in provider.
  3. In the sidebar: Firestore Database → Create Database (Start in test mode).
  4. In Project Settings (⚙️) → General → Under "Your apps" click Web (</>) → Copy the firebaseConfig object.
